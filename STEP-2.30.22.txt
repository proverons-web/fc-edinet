FC EDINEȚ v2.30.22 FULL — VISUAL EDITOR / SECTION WORKSPACE
=============================================================
SQL-МИГРАЦИИ: НЕТ. Эта версия не изменяет схему Supabase.

ЧТО ИЗМЕНИЛОСЬ
- Для страниц «Медиа», «Партнёры», «Академия» в редакторе сайта: обзор секций,
  стрелки для изменения порядка, drag-and-drop, переключение видимости секций.
- Hero закреплён в начале структуры. Это исключает случайное перемещение заголовка.
- Во встроенном Page Builder появился интерактивный просмотр НЕСОХРАНЁННОГО макета.
  Он основан на существующем ManagedPageCanvas и не изменяет публичный сайт.
- Предпросмотр поддерживает компьютер, планшет и телефон.
- Отображается индикатор несохранённых правок; подтверждение при смене вкладки,
  страницы или закрытии редактора, если в нём остался черновик.
- При сохранении черновика публичная страница не изменяется. После публикации
  родительский редактор сообщает об успехе и обновляет внешний предпросмотр.
- Перед публикацией редактор запрашивает подтверждение.
- Если порядок меню не сохранился, локальная перестановка отменяется.
- Навигация и настройки админки остаются в едином Site Builder.

УСТАНОВКА
1. Сделай резервную копию текущей рабочей версии сайта.
2. Новых миграций Supabase НЕТ. Ранее использованные миграции:
   079_multi_competitions.sql, 080_match_schedule_history.sql,
   081_cup_results.sql, 082_cup_bracket.sql, 083_cup_two_leg_ties.sql.
   Не запускай их повторно только ради версии 2.30.22.
3. Распакуй ZIP в отдельную папку; перенеси свой .env.local (его нет в архиве).
4. Запусти DEPLOY_FC_EDINET.bat. Он обязан пройти npm install, QA,
   проверку типов TypeScript и next build ДО отправки на GitHub/Vercel.
5. После публикации проверь /api/version — ожидается 2.30.22.

ПОШАГОВАЯ ПРОВЕРКА
1. /admin/site-builder → выбери «Медиа» → «Изменить страницу».
2. В блоке «Секции страницы» выбери «Фотоальбомы»; стрелками измени порядок,
   затем верни назад. Hero должен оставаться на первом месте.
3. Скрой «Видео», включи предпросмотр изменений. Секция должна исчезнуть
   ТОЛЬКО из редакторского предпросмотра; публичный сайт без публикации не меняется.
4. Переключи компьютер/планшет/телефон; проверь расположение блоков.
5. Попробуй закрыть редактор с несохранёнными правками: должно появиться
   предупреждение. Отмени закрытие, убедись, что правки остались.
6. Сохрани как ЧЕРНОВИК, проверь сообщение об успехе. Не публикуй тест.
7. Проверь аналогичную работу на «Партнёрах» и «Академии».
8. На телефоне проверь клавиши стрелок, отсутствие горизонтального переполнения,
   кликабельность кнопок и нормальное отображение подсказок.

ЗАМЕЧАНИЯ
- Данный выпуск продолжает унификацию; произвольное создание блоков для ВСЕХ
  системных страниц и canvas-drag любой DOM-ноды НЕ реализованы.
- Для страниц без Pro Page Builder действуют сохранённые прежние редакторы Hero.
- TypeScript и Next.js production build должны пройти на твоём Windows-ПК.
