FC Edineț v2.29.19 — Зал славы: поиск по иконке + единый редактор фото в админке.

1. Распаковать архив рядом с предыдущей версией, в отдельную папку fc-edinet-v2.29.19.
2. Запустить DEPLOY_FC_EDINET.bat — .env.local восстанавливается из предыдущих версий.
3. На /club/hall-of-fame проверить лупу справа над карточками: откроется окно с поиском, категориями и сбросом.
4. В админке выбрать JPG/PNG/WebP в любой обычной форме. Перед загрузкой должен открыться визуальный редактор.
5. Настроить масштаб и положение кадра, выбрать соотношение сторон, подтвердить, затем сохранить форму.
6. При пакетной загрузке медиа обработать фотографии последовательно; можно пропустить отдельные кадры.
7. Редакторы игроков, логотипов команд и Hero сохраняют собственный уже существующий crop-интерфейс.
8. Проверить npm run qa:hall, npm run qa:photo-editor, npm run qa:site и npm run qa:live после публикации.

Новые SQL-миграции не нужны. Существующие изображения в Supabase не изменяются автоматически.
