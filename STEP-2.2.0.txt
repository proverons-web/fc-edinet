FC EDINEȚ v2.2.0 — PLAYER STATISTICS FOUNDATION

Цель версии
-----------
Создать устойчивый фундамент статистики игроков до начала ручного ввода показателей.
Итоговая статистика больше не должна храниться как вручную введённые общие числа: источником становится запись игрока в конкретном матче.

Что добавлено
-------------
1. СЕЗОНЫ
- Новая таблица public.seasons.
- Название, даты начала/окончания, текущий/активный сезон.
- Существующие текстовые competition.season сохраняются и мигрируются в сезонные записи.
- Текущий рабочий сезон 2026/27 создаётся автоматически, если его ещё нет.
- Одновременно может быть только один current season.

2. ТУРНИРЫ → СЕЗОНЫ
- В competitions добавлен season_id.
- Старое текстовое поле season сохранено для обратной совместимости.
- В админке турнир можно привязать к сезону; оба поля синхронизируются.

3. СТАТИСТИКА ИГРОКА В МАТЧЕ
- Новая таблица public.player_match_stats.
- Уникальная запись: match_id + player_id.
- Уже заложены поля:
  старт/замена, позиция, капитан, минуты,
  голы, ассисты, автоголы,
  забитые/незабитые пенальти,
  жёлтые/красные карточки,
  пропущенные голы, сейвы, сухой матч,
  заметка и audit metadata.
- competition_id / season_id / club team автоматически синхронизируются из матча.

4. СОСТОЯНИЕ СТАТИСТИКИ МАТЧА
- Новая таблица match_statistics_status.
- Статус draft / complete.
- В следующих версиях это позволит отличать частично введённый матч от полностью проверенного.

5. АВТОМАТИЧЕСКИЕ ИТОГИ
- View public.player_season_statistics.
- Автоматически суммирует матчи, старты, выходы на замену, минуты, голы, ассисты, карточки, вратарские показатели.
- В агрегат попадают только finished matches.

6. АДМИНКА /admin/statistics
- Новый модуль «Статистика игроков» на главной админки.
- KPI: активные игроки, завершённые матчи, матчи со строками статистики, полностью завершённая статистика.
- Фильтры Сезон / Турнир.
- Управление сезонами и выбор текущего сезона.
- Привязка существующих турниров к сезонам.
- Список завершённых матчей и состояние их статистики.
- До применения SQL-миграции вместо падения страницы показывается понятная инструкция.

7. БЕЗОПАСНОСТЬ
- Публичное чтение активных сезонов и матчевой статистики подготовлено для будущих публичных страниц.
- Запись статистики доступна Editor/Admin.
- Удаление строк статистики и сезонов — только Admin.
- Workflow match_statistics_status видят только Editor/Admin.

ВАЖНО ПЕРЕД ПЕРВЫМ ЗАПУСКОМ
---------------------------
В Supabase → SQL Editor выполнить целиком:

database/034_player_statistics_foundation.sql

После успешного Run открыть:
/admin/statistics

Что НЕ входит в v2.2.0
----------------------
- Ручной ввод состава и показателей по игрокам — v2.2.1.
- Публичный блок статистики на странице игрока — v2.2.3.
- Лидеры / TOP-5 — v2.2.5.
