# FC Edineț v2.30.21 — Unified Site Builder

## Область изменений

Админка и Site Builder. Нет миграций базы, изменений матчей/игроков, публичных компонентов или их визуальной системы.

### Улучшения

- Главная админки получила чёткий основной сценарий и быстрые ссылки.
- Site Builder стал основным входом в редактирование страниц.
- В админ-навигации появились редактор и удобный переход к соревнованиям.
- Выбор страницы, вкладки «Дизайн / Контент», просмотр для ПК/планшета/телефона.
- Скрытые системные действия не мешают ежедневной работе.
- В меню пункты раскрываются по одному; доступны стрелки и DnD внутри одного уровня.
- При удалении пользовательской страницы/пункта требуется подтверждение.
- Для неопубликованной страницы есть безопасный текстовый предпросмотр.
- На мобильном админ-меню реализован фокус и клавиатурная навигация.
- Старый /admin/page-builder перенаправляется на единый /admin/site-builder; вложенные редакторы сохраняются.

### Ограничения

- Прямой визуальный drag-and-drop всех элементов публичных страниц пока не добавлен.
- История дизайна, сохранение/публикация остались в исходных редакторах внутри панели.
- Встроенный iframe-редактор не отслеживает потерю несохранённых полей между вкладками; добавлено предупреждение.
- Превью пользовательского черновика — упрощённое, до публикации публичная ссылка может возвращать 404.

### Проверки

Добавлены проверки на маршрутизацию, права доступа, меню и структуру интерфейса. Полный Next.js build требуется выполнить при установке.
