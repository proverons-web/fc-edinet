# FC Edineț v2.29.10 — проверка перед публикацией

## Установка и сборка

1. Распаковать новую версию рядом с предыдущими папками проекта.
2. Проверить, что `DEPLOY_FC_EDINET.bat` восстановил существующий `.env.local` из локальной предыдущей версии. Не отправлять этот файл в GitHub.
3. Выполнить `npm install`, `npm run qa:all`, `npm run build`, затем `npm audit --omit=dev`.
4. Не публиковать обновление, если `npm run build` завершился с ошибкой.
5. После деплоя убедиться, что `/api/version` возвращает `2.29.10`.

## Навигация матч ↔ игрок ↔ сезон

1. Открыть завершённый матч с **опубликованным** протоколом и составами.
2. Нажать на имя футболиста FC Edineț. Должен открыться его профиль и сезон, соответствующий сезону соревнования матча.
3. Нажать **«К игроку в протоколе матча»** — должен открыться исходный матч с подсветкой конкретной строки футболиста.
4. В протоколе нажать **«Статистика сезона»** рядом с тем же футболистом — должен открыться раздел статистики, а не шапка профиля.
5. Переключить сезон в профиле и проверить сохранение ссылки возврата в протокол.
6. Открыть карьерную статистику, выбрать один из прошлых сезонов и ещё раз проверить возврат.
7. Из блока последних матчей в профиле открыть протокол: переход должен вести к составам.
8. У футболистов соперника, для которых нет действующего клубного профиля, ссылки на профиль нет.
9. Проверить русскую и румынскую версии, ширины **320, 360, 390, 767, 768, 1280 px** и навигацию с клавиатуры.
10. Проверить, что отсутствующие статистические значения всё ещё представлены прочерком `—`, а не ложным нулём.

## QA и откат

- `npm run qa:player-nav` — проверка безопасных ссылок и передачи контекста.
- `npm run qa:player-nav-layout` — геометрия Chromium на семи ширинах.
- `npm run qa:all` — полный набор существующих проверок.
- `npm run build` — обязательная production-сборка в среде с установленными зависимостями.
- Новых миграций Supabase **нет**. Откат — возврат к предыдущему деплою v2.29.9.
