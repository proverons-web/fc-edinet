FC EDINEȚ v2.28.0 — NAVIGATION & TEAM STRUCTURE

PUBLIC NAVIGATION
- Main top-level order: Главная → Новости → Команда → Календарь → Статистика → Таблица → Клуб → Медиа.
- Команда is now a dropdown with Состав and Тренерский штаб.
- Клуб remains a dropdown with its seven section pages.
- Академия and Партнёры remain available as pages/admin data but are hidden from the primary navigation by default.
- Медиа is explicitly enabled in the primary navigation.
- Dropdown implementation was consolidated to one React-state mechanism and one dark header-matched CSS block for Chrome, Edge, Firefox and Safari.

TEAM
- /team redirects to /team/squad.
- /team/squad is the roster page.
- Removed squad summary counters, season leader cards, position filter buttons and roster search.
- Roster is now shown in a fixed football order: goalkeepers, defenders, midfielders, forwards.
- /team/staff is the standalone staff page using the existing team_staff data.
- Player profiles remain at /team/[slug].

ADMIN
- Site Builder now lists Команда — Состав and Команда — Тренерский штаб as separate system pages.
- Menu manager displays children directly after their parent.
- New menu items can be assigned to a parent directly in the create form.
- Existing /admin/players and /admin/staff remain the content sources for the two public team pages.
