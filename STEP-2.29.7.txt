FC EDINET 2.29.7 FULL

Обновление поверх v2.29.6.

Что добавлено:
- последовательное внесение событий с сохранением команды, минуты и типа (без повторного выбора игрока);
- локальный поиск игрока по фамилии/номеру;
- удобная сводка перед публикацией и отдельное обязательное подтверждение;
- серверная проверка подтверждения перед публикацией;
- автотесты qa:match-entry.

Запуск: DEPLOY_FC_EDINET.bat
Проверки: npm run qa:match-entry, npm run qa:match-workflow, npm run qa:all, npm run build.

В архиве нет .env.local и production ключей. Миграции Supabase не требуются.
