Добавлено:
- Autosave черновиков Visual Editor примерно через 1.8 сек после изменения.
- Undo / Redo в текущей сессии редактора, до 60 состояний.
- Full Screen Preview URL для черновиков; перед открытием Preview принудительно сохраняется текущее состояние.
- Preview доступен только editor/admin и не публикует черновик.
- Preflight-проверки перед публикацией.
- Safe Zone warning для главной на Desktop / Tablet / Mobile.
- Блокировка публикации при критических ошибках; предупреждения не блокируют публикацию.
- Отдельное предупреждение для нового локального crop/WebP: сам файл загружается только через «Сохранить черновик» или «Опубликовать».
- change_summary для каждой новой опубликованной версии.
- Сравнение версий в истории: before → after.
- Восстановление старой версии по-прежнему сначала создаёт черновик, а не публикует её сразу.
