FC EDINEȚ v2.2.1 — ВВОД СТАТИСТИКИ ИГРОКОВ ПО МАТЧУ
=======================================================

Что добавлено
-------------
1. Завершённый матч теперь открывается из /admin/statistics в отдельном редакторе.
2. Для каждого игрока можно отметить участие и выбрать: старт / замена.
3. Основные показатели: минуты, голы, ассисты, ЖК, КК, капитан.
4. Дополнительно: автоголы, забитые/незабитые пенальти, заметка.
5. Для вратаря: пропущенные голы, сейвы, сухой матч.
6. Два состояния сохранения: черновик и статистика завершена.
7. Повторное открытие матча загружает уже сохранённые значения.
8. Снятие отметки «Играл» удаляет статистическую строку этого игрока из матча.
9. В списке матчей видны статусы: Не заполнено / Черновик / Готово.

База данных
-----------
034 в этом полном архиве уже содержит исправленный UUID для players.id.
Если 034 уже успешно применена ранее, повторять её НЕ НУЖНО.

Для v2.2.1 ОДИН РАЗ выполни:
  database/035_player_statistics_entry.sql

035 разрешает Editor/Admin корректно убирать игрока из статистики матча
и добавляет нормальное обновление updated_at.

Проверка после deployment
-------------------------
1. /api/version -> 2.2.1
2. /admin/statistics
3. Открыть завершённый матч -> «Ввести статистику».
4. Отметить 2–3 игроков, заполнить цифры -> «Сохранить черновик».
5. Перезагрузить страницу -> значения должны остаться.
6. «Сохранить и завершить» -> матч должен получить статус «Готово».
