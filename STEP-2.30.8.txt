УСТАНОВКА НА WINDOWS
1. Распакуй ZIP в НОВУЮ папку, не смешивай со старой версией.
2. Скопируй в неё свой .env.local из предыдущей рабочей папки.
3. Рекомендуется проверить в .env.local значение:
     NEXT_PUBLIC_SITE_URL=https://fc-edinet.vercel.app
   Не публикуй содержимое .env.local и не отправляй ключи в чат.
   Если переменная отсутствует, сервер использует домен production Vercel.
4. Запусти DEPLOY_FC_EDINET.bat.
5. При ошибке DEPLOY FAILED отправка файлов в GitHub не выполняется.
   Скопируй полный вывод ошибки, включая строку FAIL выше сообщения.
6. При SUCCESS дождись статуса READY в Vercel.
7. Открой https://fc-edinet.vercel.app/api/version (ожидается v2.30.8).

ЧТО ПОЯВИЛОСЬ
• Красивое автоматическое 1200x630 превью для опубликованных новостей:
  фотография + фирменные цвета + герб + заголовок + дата.
• Аналогичное превью для опубликованных фотоальбомов.
• Сохранено персональное превью матчей с результатом и гербами команд,
  теперь оно запрашивает актуальные сведения при обращении бота.
• Унифицированы og:image / twitter:image, canonical и размер карточки.
• URL изображения содержит отметку updated_at, чтобы после правок
  менялся адрес картинки (социальная сеть всё ещё может кэшировать
  саму ссылку на статью до повторной переиндексации).
• Фотоальбомы используют WebP-миниатюры. Для стабильного превью они
  автоматически преобразуются в JPEG на сервере (sharp).
• Недоступные и недоверенные файлы не могут сломать превью:
  срабатывает фирменный резервный фон.

ПРОВЕРКА
1. Открой опубликованную новость: /news/<slug>.
   Проверь: /news/<slug>/opengraph-image — должна вернуться PNG-карточка.
2. Открой фотоальбом: /media/<slug>.
   Проверь: /media/<slug>/opengraph-image.
3. Открой существующий матч: /matches/<id>.
   Проверь: /matches/<id>/opengraph-image. Показан фактический счёт
   только при наличии результата, иначе VS.
4. В исходном HTML публичной страницы проверь og:title, og:image,
   og:image:width, og:image:height, twitter:card, canonical.
5. Размести тестовую ссылку в Telegram или Facebook. Некоторые
   платформы кэшируют старые изображения: Facebook Sharing Debugger
   позволяет повторно сканировать URL, Telegram может обновляться позже.
6. Проверь RU и RO в браузере, а также обычный вид страниц на телефоне.

ВОЗМОЖНОЕ ОГРАНИЧЕНИЕ
• Существующая языковая схема сайта опирается на cookie, поэтому
  поисковые/социальные боты без сохранённого выбора языка могут
  получать вариант по умолчанию (RU). Это не отдельные RU/RO URL.
• Production build Next.js должен пройти на Windows: в среде сборки
  архива npm Registry временно недоступен (EAI_AGAIN).

Не выполнять SQL и не заменять файлы вручную, кроме копирования .env.local.
