# FC Edineț v2.30.22 — Visual Editor Improvements

## Основные изменения

- Единый workflow в `/admin/site-builder` сохранён.
- Встроенный Page Builder Pro (Медиа, Партнёры, Академия) получил переключаемый
  интерактивный **предпросмотр текущих несохранённых изменений** на трёх размерах.
- Стрелки для изменения порядка секций, доступные без drag-and-drop; Hero
  остаётся первым. Скрытие секции не удаляет её.
- Отслеживание несохранённых изменений во встроенном редакторе, защита
  от непреднамеренного закрытия / смены вкладки или страницы.
- Сообщение после успешного сохранения черновика или публикации и обновление
  публичного предпросмотра только после публикации.
- Отдельные адаптивные стили для секций и редакторской панели.
- Подтверждение перед публикацией изменений на сайте; откат локального порядка меню при ошибке сохранения.

## Совместимость

Существующие данные, Supabase RLS, админские роли, маршруты и текущие
публикации не изменены. SQL-миграций нет. При сохранении используется
стандартный `saveProPageLayout`; отмена и повтор действий остаются доступны.

## Ограничения

Системные Hero-редакторы сохранены: это не универсальный DOM-конструктор
всех публичных страниц. `next build` требует установленных npm-зависимостей.
