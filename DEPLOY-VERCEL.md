# FC Edineț v2.29.9 — локальная сборка и публикация

## Установка

1. Распакуйте полный пакет `fc-edinet-v2.29.9` рядом с предыдущими папками.
2. Запустите `DEPLOY_FC_EDINET.bat` из корня распакованной папки.
3. Скрипт ищет `.env.local` в предыдущих локальных версиях и безопасно копирует его при отсутствии настроек. **Не публикуйте `.env.local` в GitHub.**
4. При успешном `npm run deploy:check` скрипт коммитит код и отправляет изменения в `github.com/proverons-web/fc-edinet.git`, откуда начинается автоматическая сборка Vercel.
5. После завершения Vercel deployment проверьте `https://fc-edinet.vercel.app/api/version` (ожидается `v2.29.9`).

## Переменные среды

На Vercel в соответствующих окружениях должны быть заданы значения для Supabase, используемые текущим сайтом. Нельзя помещать `SUPABASE_SECRET_KEY`, `ANALYTICS_IP_SALT` и другие серверные секреты под префикс `NEXT_PUBLIC_`.

Для локальной проверки нужен `.env.local` с `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` и другими переменными, уже используемыми проектом. **Пакет не содержит секретов.**

## Тесты перед деплоем

```powershell
npm install
npm run qa:match-workflow
npm run qa:public-match
npm run qa:all
npm run build
npm audit --omit=dev
```

В `npm run deploy:check` также включены QA и production build. Если установлены Node.js 22.16+ и Chrome/Edge, Responsive QA выполняется локально. Если нет — следуйте сообщению инструмента, не называйте пропущенную проверку успешно пройденной.

## Контроль после деплоя

См. `PRODUCTION-CHECKLIST-v2.29.9.md`. Убедитесь, что все серверные действия сохраняют данные, а несохранённые изменения форм действительно блокируют случайную навигацию. Новый релиз не содержит SQL-миграций. В публичном протоколе добавлены пять показателей игрока в составе опубликованного протокола, защищённые от подстановки неподтверждённых чисел; остальные страницы не менялись.

## Восстановление

Предыдущие полные версии и их `.env.local` оставьте на месте до прохождения проверок. При ошибках смотрите логи BAT, Vercel build и сообщения в админке. Временный откат Vercel осуществляйте только после проверки миграций и состояния базы; этот релиз миграций не содержит.
