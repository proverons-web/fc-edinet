НОВОЕ
1) Перед заменой GitHub main установщик создает и проверяет Git bundle предыдущего origin/main.
   Папка по умолчанию: рядом с проектом, FC_Edinet_DeployBackups.
   Файл .bundle — архив исходного Git-репозитория, а НЕ резервная копия Supabase.
2) Перед коммитом установщик проверяет Git staging: ключи, файлы .env.production,
   закрытые ключи, GitHub/OpenAI/Supabase-токены и npm authentication.
   При подозрении отправка в GitHub блокируется; значения секретов не печатаются.
3) Добавлены HSTS и явный запрет публичных production source maps.
4) Дополнительный QA в установщике и GitHub Actions проверяет откат и секреты.

ПОРЯДОК УСТАНОВКИ
1. Убедиться, что v2.30.25 работает. Скопировать существующую папку проекта отдельно.
2. Supabase: сделать реальную резервную копию БАЗЫ (Supabase Dashboard -> Database -> Backups,
   если функция доступна на текущем тарифе). Если Backups недоступен — выполнить
   логический экспорт поддерживаемым инструментом pg_dump из защищенной среды.
   Отдельно сохранить объекты Supabase Storage — резервная копия SQL их не содержит.
   Проверить доступность восстановительной копии. НЕ отправлять дамп в GitHub/чат.
3. Распаковать fc-edinet-v2.30.26-FULL.zip в новую папку.
4. Перенести .env.local из прошлой версии; НЕ публиковать его и НЕ прикладывать к заявкам.
5. Запустить DEPLOY_FC_EDINET.bat. Сначала npm install, QA, TypeScript и Next.js build.
   Если build / guard / Git backup не прошел, push НЕ выполняется.
6. После git fetch установщик сохраняет предыдущий origin/main в *.bundle
   рядом с проектом (FC_Edinet_DeployBackups), проверяет архив, затем обновляет Git.
7. Перед git commit выполняется guard-staged-secrets.mjs. Если обнаружена проблема,
   удалить секреты из Git index и повторить установку. При реальной утечке сменить ключ.
8. Проверить на https://fc-edinet.vercel.app/api/version версию 2.30.26,
   только ПОСЛЕ того, как Vercel покажет READY.
9. Пройти вручную: вход в админку, создание черновика, календарь, избранное,
   уведомления, статистика и /admin/diagnostics/performance.

- Архив .bundle содержит коммит предыдущей main. Хранится ЛОКАЛЬНО, вне проекта.
