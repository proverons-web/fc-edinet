# FC Edineț v2.29.6 — контроль после публикации

- [ ] `/api/version` показывает **2.29.6**; предыдущие версии сайта не удалены до успешной проверки.
- [ ] Открывается реальный матч в `/admin/match-center/[matchId]` под учётной записью администратора.
- [ ] Для завершённого матча с 10 футболистами в одном из составов список задач указывает неполный состав и ведёт в соответствующий раскрытый раздел.
- [ ] Для незавершённого матча список не требует публикацию и не ошибочно считает необязательную статистику блокером.
- [ ] Клик по пунктам навигации «События», «Отчёт» и «Статистика команд» раскрывает `<details>` и прокручивает к форме.
- [ ] Изменения в поле «Главный судья», числовом поле счёта, составе и событии отслеживаются; возврат к исходному значению снимает индикатор.
- [ ] Внутренние ссылки, боковая навигация и браузерная перезагрузка предупреждают о несохранённых изменениях; отмена оставляет данные в форме.
- [ ] При сохранении одной из двух изменённых форм появляется предупреждение о потере других правок.
- [ ] Сохранение единственной изменённой формы не вызывает лишнего подтверждения, а индикатор очищается после успешного обновления.
- [ ] Готовность публикации не допускает отсутствующий итоговый счёт; серверное действие также отклоняет такую попытку.
- [ ] Голы, автоголы, красные/жёлтые карточки, замены и сезонные показатели работают по прежней логике.
- [ ] На мобильном экране список задач идёт в одну колонку; публичные страницы выглядят как раньше.
- [ ] `npm run build`, `npm run qa:all`, `npm audit --omit=dev` проходят на Windows; повторно проверить GitHub Actions после push.

**Важно:** список рекомендаций не меняет обязательные правила публикации — ими остаются завершённый матч, заданный счёт и совпадающая сумма голов таймлайна. Черновики автоматически в базу не записываются.
