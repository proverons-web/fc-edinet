# FC Edineț v2.29.7 — проверка перед публикацией

1. Распакуй полный пакет рядом с v2.29.6. Запусти DEPLOY_FC_EDINET.bat, который восстановит переменные из предыдущей папки при необходимости.
2. Проверь версию `/api/version` = 2.29.7 после деплоя.
3. Открой /admin/match-center/{id} под действующим администратором.
4. Выбери событие, команду и минуту; найди игрока по фамилии/номеру. Сохрани через «Сохранить и добавить ещё».
5. Убедись: тип, команда, минута сохранились в новой форме, но основной и связанный игрок очищены; событие записано ровно один раз.
6. Повтори с кнопкой «Сохранить и закончить»: контекст сброшен.
7. Проверь голы/автогол/карточку/замену, автоматический пересчёт и редактирование существующего события.
8. Открой «Публикация»: незакрытые обязательные проверки должны блокировать кнопку. Дополнительные рекомендации не блокируют.
9. После готовности страницы поставь галочку сверки; только затем должна разблокироваться публикация. Попытайся отправить серверный запрос без галочки — публикация должна быть отклонена.
10. Проверь мобильный редактор (360/390 px) и внешний протокол матча.
11. Выполни npm run qa:all, npm run build и npm audit --omit=dev; реальные результаты запиши в чек-лист.

Миграций базы данных нет. Продакшн Supabase не изменялся.
