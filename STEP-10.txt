FC EDINET — v1.0

ЧТО НОВОГО
1. Номера игроков на фото стали контрастными:
   - синяя плашка
   - белые цифры
   - белая рамка
   - тень

2. Кадрирование фотографий:
   - выбрать исходное фото
   - открывается редактор
   - двигать фото
   - zoom 1x–3x
   - фиксированная рамка 4:5
   - сохраняется готовый WEBP 1000x1250
   - в Storage загружается уже выбранный участок

3. Модуль матчей:
   - teams
   - competitions
   - matches
   - /admin/matches
   - /admin/matches/teams
   - /matches
   - следующий матч на главной
   - последний результат на главной

УСТАНОВКА
1. Скопировать .env.local из v0.9.1.
2. Supabase SQL Editor:
   выполнить database/007_matches.sql
3. npm install
4. npm run build
5. npm run dev

ПРОВЕРКА КАДРИРОВАНИЯ
/admin/players -> Редактировать -> выбрать новое фото.
Откроется окно кадрирования.
Перетащи нужного человека в рамку, увеличь масштаб и нажми
«Использовать этот кадр».
Затем «Сохранить игрока».

ПРОВЕРКА МАТЧЕЙ
/admin/matches/teams
- добавить соперника

/admin/matches/new
- выбрать хозяев/гостей
- Liga 2
- дата/время
- стадион
- статус Предстоящий
- сохранить

После этого матч появится:
- на главной в «Следующий матч»
- на /matches

После игры:
- открыть матч
- статус Завершён
- ввести счёт
- сохранить

Он автоматически станет «Последним матчем» на главной.
