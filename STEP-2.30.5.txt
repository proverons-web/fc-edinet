FC EDINET v2.30.5 FULL — Album Experience Fix

IMPORTANT: This release continues directly from v2.30.4. No intermediate release required.

INSTALLATION (Windows)
1. Keep a backup of the v2.30.4 folder and local .env.local.
2. Run the ADDITIVE SQL migration in the FC EDINET Supabase project:
   database/076_media_album_cover_focus.sql
   Open Supabase Dashboard -> SQL Editor, paste its content and execute once.
   Existing albums are preserved. New X/Y positions default to 50%.
3. Extract the complete ZIP to a NEW folder (do not merge with an old version).
4. Copy YOUR existing .env.local if using it locally (never share secrets).
5. Run DEPLOY_FC_EDINET.bat. All QA checks and production build must pass
   before the installer pushes to GitHub. Then confirm Vercel is READY.
6. Check https://fc-edinet.vercel.app/api/version (expected v2.30.5).
7. In /admin/media/[id]/edit, drag the COVER PREVIEW or adjust X/Y sliders.
   Click Save settings. Then refresh /media/[slug] and check the hero.
8. Open a published album, click a photo and verify centered full image,
   arrow navigation, filmstrip, Esc, keyboard Home/End, and mobile swipe.

NOTES
- The manual hero positioning applies when the album page template's
  background mode is CONTENT. If it is CUSTOM, that template image and its
  own site-builder position remain authoritative.
- A thumbnail is kept for album cards; the album hero now uses the full image
  when it matches a published photo in the album.
- No public site changes were deployed by creating this ZIP.
- Do not run migration 076 in another Supabase project.
