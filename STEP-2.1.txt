FC EDINET v2.1 — КОММЕНТАРИИ, МОДЕРАЦИЯ И ДИАГНОСТИКА ПЕРЕВОДА

1. Комментарии к опубликованным новостям:
   - писать могут авторизованные пользователи;
   - до 2000 символов;
   - один комментарий не чаще одного раза в 20 секунд;
   - пользователь может удалить свой комментарий;
   - RU/RO интерфейс комментариев.

2. Жалобы:
   - спам;
   - оскорбительный контент;
   - травля/преследование;
   - другое;
   - одна жалоба от пользователя на один комментарий.

3. Админка /admin/comments (editor/admin):
   - новые жалобы;
   - последние комментарии;
   - скрыть / восстановить;
   - отклонить жалобу;
   - скрыть комментарий и закрыть связанные жалобы;
   - блокировка комментариев на 1/7/30 дней или без срока;
   - снятие блокировки.

4. Безопасность:
   - RLS для comments/comment_reports/comment_blocks;
   - блокировка действует на уровне БД;
   - имя и аватар комментария заполняются серверным trigger из профиля;
   - rate-limit также проверяется серверным trigger;
   - обычный пользователь не может модерировать чужие комментарии.

5. Автоперевод RU -> RO:
   - точная диагностика OpenAI API;
   - HTTP status, error type, error code, message, Request ID;
   - отдельная кнопка "Проверить OpenAI API";
   - журнал последних запросов /admin/translations;
   - ошибки больше не скрываются за общим счётчиком 0/8.

6. SQL:
   database/022_comments_moderation_translation_diagnostics.sql

Версия: 2.1.0
