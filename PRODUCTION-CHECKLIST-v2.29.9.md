# FC Edineț v2.29.9 — production checklist

1. На Windows распаковать рядом с предыдущими версиями, запустить `DEPLOY_FC_EDINET.bat`; убедиться в успешном `next build` и адресе `/api/version` (ожидается `v2.29.9`).
2. Открыть опубликованный матч с завершённой статистикой: пять показателей каждого игрока должны совпадать с `player_match_stats`, в том числе нули.
3. Открыть опубликованный матч с ещё не завершённой статистикой: минуты и ассисты должны показывать `—`; реальные события голов и карточек сохраняются.
4. Проверить счёт, автоголы, красные после второй жёлтой, замены и ссылки на профиль — старое поведение должно сохраниться.
5. Проверить команды с одинаковыми ФИО: голы и карточки не должны переноситься между командами.
6. Проверить RU и RO на 320, 360, 390, 768, 1280 px; отсутствие горизонтальной прокрутки, читаемость шрифтов и отсутствие перекрытий значков.
7. Проверить в админке матча сохранение и публикацию, убедиться в отсутствии новых RLS/403 ошибок.
8. Выполнить `npm run qa:all`, `npm run qa:player-layout`, `npm run build`, `npm audit --omit=dev`; зафиксировать ошибки и результаты.

Изменения публичного интерфейса находятся только в `app/matches/[id]/match-player-stats-v2299.css`; новые правила не затрагивают глобальную мобильную вёрстку. Новых SQL-миграций нет.
