FC Edineț v2.28.18 — IP-Unique Site Analytics

What changed
- Unique visitor identity now uses a server-side HMAC hash of the public client IP. Raw IP addresses are never stored.
- Vercel Preview/Development traffic is excluded from production audience analytics.
- Legacy browser-ID analytics are preserved in the database but excluded from current dashboards.
- Country, device, language and viewport shares are calculated from unique IP visitors, not pageviews.
- Each unique IP is assigned to its latest dimension value in the selected period so demographic shares have a coherent denominator.
- Expanded bot/user-agent filtering for common automated clients.
- Added migration 064_ip_unique_analytics.sql and record_site_visit_v3().
- Version synchronized to 2.28.18.
- Public analytics ingest is guarded by a server-only ingest proof; legacy RPCs are retired.
