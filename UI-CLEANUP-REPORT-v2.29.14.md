# FC Edineț v2.29.14 — CSS cleanup report

## Scope

Этот релиз намеренно **не меняет утверждённый дизайн**. Очищены только ранние CSS-декларации, для которых в том же файле существует более поздняя декларация с **точно тем же селектором, тем же @media/@supports-контекстом, тем же свойством, значением и флагом `!important`**. Не затрагивались значения, различающиеся между историческими вариантами, и не менялся порядок подключения файлов.

| Файл | Удалено идентичных деклараций | Снято `!important` |
|---|---:|---:|
| `app/globals.css` | 45 | 1 |
| `app/visual-polish.css` | 66 | 55 |
| `app/home-v215.css` | 103 | 101 |
| `app/mobile.css` | 1 | 1 |
| **Итого** | **215** | **158** |

Итоговый исторический CSS-бюджет: **4080** `!important` вместо **4238**. Это не значит, что остальные правила безопасно удалять автоматически.

## Protection

- `qa/css-baseline.json`: новый максимальный лимит overrides.
- `qa/baselines/ui-v2.29.13-css.json.gz`: неизменённые CSS v2.29.13, чтобы сравнивать в одном Chromium, без влияния версии браузера.
- `scripts/qa-ui-consistency.mjs`: пять контрольных макетов × четыре ширины (320/390/768/1280) = **20 пар снимков**.
- `qa/fixtures/profile-hero.html`: контроль расположения навигации/портрета/информации игрока.
- `qa:ui` включена в `qa:all`, `deploy:check` и GitHub Actions.
- `qa:live` и `qa:public-integrity` получают текущую версию из `package.json`.

## Known limitations

Сверка синтетических DOM-компонентов не заменяет реального браузерного аудита production с Supabase. Административные страницы за авторизацией в данном тесте не открываются. `next build` подтверждается только при наличии всех зависимостей и переменных среды.
