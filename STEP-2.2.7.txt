FC EDINEȚ v2.2.7 — ФИНАЛЬНЫЙ QA СИСТЕМЫ СТАТИСТИКИ
=======================================================

Что добавлено:

1. Финальная миграция 040_statistics_final_qa.sql
   - проверки ударов и передач на уровне БД;
   - чистый матч вратаря нельзя хранить вместе с пропущенными голами;
   - при смене сезона у турнира уже введённая статистика автоматически получает новый season_id;
   - завершить статистику можно только для finished-матча с турниром, сезоном и хотя бы одним игроком;
   - создан editor-only view statistics_integrity_issues для автоматической диагностики.

2. /admin/statistics
   - новый QA-блок «Целостность данных»;
   - показывает ошибки и предупреждения;
   - из замечания можно сразу открыть проблемный матч;
   - диагностируются: матч без турнира/сезона, complete без игроков, рассинхрон контекста, несколько капитанов, статистика у незавершённого матча.

3. Ввод статистики матча
   - завершение требует хотя бы одного игрока в старте;
   - завершение требует хотя бы одного вратаря;
   - нельзя завершить матч с несколькими капитанами;
   - выбор капитана в интерфейсе автоматически снимает капитанство с другого игрока;
   - clean sheet + пропущенные голы блокируется;
   - если у матча нет турнира или у турнира нет сезона, черновик сохранить можно, а завершить нельзя.

4. Публичные таблицы и мобильные экраны
   - финальная адаптация широких таблиц;
   - имя игрока остаётся видимым при горизонтальной прокрутке на небольшом экране;
   - улучшены sticky save bar и сводка формы на телефоне.

Установка:
1. Supabase -> SQL Editor -> выполнить database/040_statistics_final_qa.sql ОДИН РАЗ.
2. Запустить DEPLOY_FC_EDINET.bat.
3. Проверить /api/version -> 2.2.7.
4. Открыть /admin/statistics и убедиться, что блок QA появился.
