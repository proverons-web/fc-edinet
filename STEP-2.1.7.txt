FC EDINEȚ v2.1.7 — BLOCK LIBRARY

Цель версии:
- превратить Section Builder в настоящий конструктор главной;
- добавить + Добавить блок без редактирования исходного кода;
- смешивать стандартные секции и пользовательские блоки в одном порядке;
- сохранять всё через общий черновик Visual Editor и историю публикаций.

Новые блоки:
- Текст;
- Изображение;
- Текст + изображение;
- Баннер / CTA;
- Новости;
- Игроки;
- Медиа;
- Партнёры;
- Следующий матч;
- Турнирная таблица.

Каждый пользовательский блок поддерживает:
- показать / скрыть;
- drag & drop в общей структуре главной;
- дублирование и удаление;
- RU / RO заголовки и текст с fallback на RU;
- ширину Container / Wide / Full width;
- фон inherit / light / dark / brand;
- отступы сверху и снизу;
- адаптивную сетку Desktop / Tablet / Mobile для карточных блоков;
- количество элементов;
- выбор изображения из Media Library для визуальных блоков.

База:
- database/029_block_library.sql;
- homepage_blocks — опубликованные пользовательские блоки;
- homepage_design_draft.custom_blocks — полный блоковый черновик;
- homepage_design_draft.layout_order — единый порядок системных секций и пользовательских блоков.

Публичная главная объединяет homepage_sections и homepage_blocks по display_order.
Удаление блока происходит только при публикации дизайна; до этого оно существует только в черновике.
