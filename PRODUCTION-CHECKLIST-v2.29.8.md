# FC Edineț v2.29.8 — проверка релиза

1. Проверить /api/version → 2.29.8.
2. Открыть опубликованный протокол матча с событиями на телефоне; фильтр «Все» должен показывать хронологию целиком.
3. Переключить «Голы», «Карточки», «Замены» и сверить количество с реальными событиями; «Все» восстанавливает полный список.
4. Проверить, что на ПК осталась прежняя горизонтальная шкала (без фильтра).
5. Открыть матч, у которого статистика внесена не полностью: прочерки «—» должны означать «нет данных», без ложных нулей и ложных сравнений.
6. Проверить, что одинаковые показатели создают одинаковые по длине зеркальные полосы.
7. Проверить поиск игрока в админском редакторе события: счётчик меняется, сохранение работает как прежде. Попытка замены одного игрока самим собой должна отклоняться.
8. Выполнить `npm run qa:all`, `npm run build`, затем production deploy.

Миграция Supabase не требуется. Production build в среде подготовки пакета может отсутствовать — проверять в Windows.
