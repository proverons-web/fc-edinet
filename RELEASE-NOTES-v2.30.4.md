# FC Edineț v2.30.4 FULL — Video Match Center

Основа: полный архив v2.30.3. Версия в `package.json`, `lib/release.ts`, `/api/version` и админ-диагностике теперь едина: **2.30.4**. Ошибка наследования `2.30.2` из v2.30.3 устранена.

## Что добавлено
- У каждой YouTube-записи необязательный матч (`match_id`) и категория (`video_kind`): highlights, full_match, interview, other.
- Административная форма создания видео с выбором категории/матча.
- **Новая страница редактирования** `/admin/media/videos/[id]/edit` — название, ссылка, дата, описание, тип, матч, публикация, закрепление на главной.
- В протоколе `/matches/[id]` блок «Видео матча» появляется для опубликованных привязанных записей.
- Ссылка на протокол в публичной медиатеке для привязанных видео; категория видео на карточке RU/RO.
- Безопасное извлечение YouTube ID из разрешённых доменов; отклоняются домены-имитаторы.
- Миграция `database/075_media_match_videos.sql` не удаляет старые видео, добавляет индекс; прежние записи остаются с категорией `other` и без привязки.

## Совместимость
- Фотогалереи, медиатека v2.30.3, избранное и протоколы остаются на месте.
- До применения SQL-миграции публичные протоколы продолжат работать без видеоблока; админские операции с новыми полями будут выдавать понятную ошибку БД.
- Публичные видеокарточки используют существующий YouTubePlayer с загрузкой iframe только после нажатия.

## Проверка
- `npm run qa:all` — регрессионные проверки исходного проекта.
- `node --experimental-strip-types scripts/qa-match-videos-v2304.mjs` — проверки новой версии, включая адреса YouTube.
- `npm run deploy:check` — полная проверка и production Next.js build, требует установки npm-зависимостей.

## Ручная проверка
1. Создать опубликованное видео, привязанное к матчу — появляется в протоколе.
2. Снять публикацию — исчезает из протокола.
3. Изменить связь на другой матч — видео отображается только у нового матча.
4. Добавить короткую YouTube-ссылку; убедиться, что предпросмотр корректен.
5. Открыть RU/RO на телефоне.
6. Сверить `/api/version` с локальным релизом.
