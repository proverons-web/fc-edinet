# FC Edineț v2.30.12 FULL — CSS Optimization & Final Polish

Основа: **v2.30.11 FULL FIX1**. Без SQL-миграций. Публичный дизайн и функции матч-центра сохранены.

## Изменения

1. Из четырёх глобальных таблиц стилей удалены **39 пустых CSS-правил** (включая пустые селекторы матч-центра, карточек игроков и мобильных карточек). Значимые определения и порядок подключённых файлов сохранены.
2. Добавлены визуальные контуры фокуса только при управлении клавиатурой (`:focus-visible`). На тёмном фоне используются фирменные жёлтые контуры, на светлом — синие.
3. При включённой системной опции уменьшения движения отключено плавное прокручивание и переходы нескольких ключевых элементов, включая главные фотокарточки и предпросмотр редактора.
4. Новый `scripts/qa-css-polish-v2312.mjs` проверяет баланс скобок/строк/комментариев, отсутствие пустых правил, последовательность импорта CSS, настройки фокуса и доступности, размер CSS и согласованность релиза.
5. Новая проверка встроена в `npm run qa:all`, `npm run deploy:check` и `.github/workflows/responsive-qa.yml`.

## Фактический эффект и ограничения

Общий размер исходников четырёх CSS: **885 481 → 884 331 байт** (−1 150). Это небольшая очистка технического долга, **не подтверждённое ускорение загрузки**, поскольку производственная сборка сама оптимизирует CSS. Массовое объединение исторических CSS-переопределений сознательно отложено: оно могло бы разрушить утверждённый макет.
