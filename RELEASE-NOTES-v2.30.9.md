# FC Edineț v2.30.9 — Match Social Logos

## Изменения

- Переработан шаблон Open Graph / Twitter-карточки матча (1200 × 630 px).
- Внедрены отдельные крупные логотипы обеих команд из `teams.logo_url`.
- Каждый герб помещается в одинаковую область 214 × 214 px; само изображение занимает до 178 × 178 px с `object-fit: contain`. Пропорции и прозрачность сохраняются.
- Исходные PNG, JPEG и WebP преобразуются на сервере в компактные PNG 200 × 200 px (прозрачный фон). Это устраняет зависимость рендера от формата/размера исходного файла.
- Если герб временно не загружается, для команды клуба применяется локальный `fc-edinet-crest.png`, для остальных — сокращённое обозначение команды.
- Счёт остаётся по центру, названия команд — под логотипами. Длинные названия уменьшаются по размеру.
- В адрес `og:image` добавлена версия релиза `r=2.30.9` для обновления кэша социальных сетей.
- Сохранены реальные счёт, дата, соревнование и стадия из базы. Нет выдуманных данных.

## Совместимость и установка

Полный проект, основан на FC Edineț v2.30.8. Новых SQL-миграций нет. Привязка логотипов к командам уже присутствует в Supabase.

Запуск на Windows: распаковать ZIP в новую папку, скопировать свой `.env.local`, запустить `DEPLOY_FC_EDINET.bat`. Развёртывание проводится самим пользователем; ZIP не опубликован автоматически.

## Проверка

- `/matches/17/opengraph-image?r=2.30.9` — матч FC Edineț — CF Locomotiva, оба PNG-логотипа из Supabase.
- В соцсетях проверять ссылку `/matches/17`, а не только изображение. Социальные сети могут сохранять ранее закэшированные карточки, используйте повторную проверку/сканирование ссылки.
- Другой матч с длинным названием команды — убедиться, что герб и название умещаются.

## Ограничение тестовой среды

Все локальные QA пройдены. Непосредственная production-сборка Next.js в этой среде не подтверждена: пакетные зависимости не установлены, npm Registry временно недоступен. Установщик на Windows запускает её перед публикацией.
