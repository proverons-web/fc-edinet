FC EDINEȚ v2.6.8 — GitHub deploy guard fix

Fixes the failed GitHub push caused by node_modules being added to Git.

Changes:
- added a complete .gitignore for node_modules, .next, .vercel, local env files, logs and local tooling caches
- DEPLOY_FC_EDINET.bat now verifies that node_modules is ignored before committing
- deploy script removes generated directories from the Git index before git add
- git add now uses -A after the cleanup
- deploy script checks tracked/staged working files against a 95 MB safety threshold before commit/push
- prevents GitHub's 100 MB single-file limit from being hit by generated dependencies
- no application UI or Supabase schema changes

Deployment:
1. Extract v2.6.8 into a fresh folder.
2. Copy ONLY your working .env.local from the previous version.
3. Run DEPLOY_FC_EDINET.bat.
4. Verify https://fc-edinet.vercel.app/api/version -> 2.6.8

Do not copy node_modules, .next, .git or .vercel from an older folder.
