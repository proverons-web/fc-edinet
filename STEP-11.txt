FC EDINET — v1.1

ЧТО НОВОГО
1. При создании новой команды можно загрузить логотип.
2. Для уже созданных команд появилась отдельная страница редактирования.
3. Логотипы команд отображаются:
   - в блоке «Следующий матч»
   - в блоке «Последний матч»
   - на странице /matches
   - в hero-блоке следующего матча
4. Storage bucket для логотипов команд:
   teams

УСТАНОВКА
1. Скопировать .env.local из v1.0 в v1.1.
2. В Supabase SQL Editor выполнить:
   database/008_team_logos.sql
3. npm install
4. npm run build
5. npm run dev

КАК ПРОВЕРИТЬ
1. Открыть /admin/matches/teams
2. Добавить новую команду с логотипом
3. Либо открыть существующую команду -> Редактировать -> загрузить логотип
4. Затем создать матч или открыть уже существующий матч с этой командой
5. Проверить главную страницу:
   - Следующий матч
   - Последний матч
6. Проверить /matches

ВАЖНО
Для FC Edineț тоже зайди в редактирование команды и добавь логотип клуба,
иначе в матчах у нашего клуба будет fallback-значок с буквами.
