FC EDINEȚ v2.3.0 — MATCH CENTER / ФУНДАМЕНТ СТАТИСТИКИ МАТЧА
================================================================

Что добавлено:

1. Миграция 041_match_statistics_foundation.sql
   - match_reports — основа отчёта по матчу;
   - match_team_statistics — по одной строке для хозяев и гостей;
   - match_events — фундамент таймлайна событий;
   - match_center_progress — editor-only view для статуса заполнения;
   - автоматическая синхронизация home/away team rows при изменении матча;
   - RLS: новые черновые данные доступны только Editor/Admin.

2. Новый раздел /admin/match-center
   - единый список матчей;
   - фильтры Все / Завершённые / Предстоящие;
   - статус основы отчёта;
   - статус статистики игроков v2.2;
   - готовность двух строк командной статистики;
   - счётчик событий будущего таймлайна.

3. Страница /admin/match-center/[matchId]
   - судья;
   - посещаемость;
   - погода;
   - состояние поля;
   - лучший игрок матча;
   - краткий отчёт;
   - проверка foundation rows HOME/AWAY;
   - переход в уже существующий редактор статистики игроков.

4. Навигация
   - новый модуль «Матч-центр» в админке;
   - кнопка «Матч-центр» в списке обычных матчей.

Следующие шаги ветки v2.3:
- v2.3.1 — события матча / таймлайн;
- v2.3.2 — стартовые составы и замены;
- v2.3.3 — командная статистика;
- v2.3.4 — публичная страница матча;
- v2.3.5 — MVP и расширенные связи;
- v2.3.6 — visual/mobile pass;
- v2.3.7 — финальный QA.

Установка:
1. Supabase -> SQL Editor -> выполнить database/041_match_statistics_foundation.sql ОДИН РАЗ.
2. Запустить DEPLOY_FC_EDINET.bat.
3. Проверить /api/version -> 2.3.0.
4. Открыть /admin/match-center.
