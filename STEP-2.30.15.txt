Production Monitoring, Node.js 22.x & RUM Diagnostics
=========================================================
SQL-МИГРАЦИИ: НЕТ (новых миграций в v2.30.15 нет)

ЧТО ИЗМЕНИЛОСЬ
- Версия Node.js закреплена за основной веткой 22.x. Это предотвращает
  автоматический переход Vercel на новую основную ветку Node.js.
- Предупреждение npm "Unknown env config cache-dir" возможно создаётся самой
  сборочной средой Vercel. Оно не указывает на проблему проекта, и мы не
  отключаем проверки npm ради сокрытия предупреждения.
- Админка мониторинга показывает состояние приёмника, время последней записи,
  фильтр по устройствам и предупреждения при малой выборке.
- Добавлены регрессионные тесты мониторинга и защиты текущей версии.

УСТАНОВКА
1. На всякий случай сохрани рабочую папку предыдущей версии и .env.local.
2. Распакуй этот ZIP в НОВУЮ папку fc-edinet-v2.30.15.
3. Перенеси .env.local из предыдущей папки. Не отправляй и не публикуй
   этот файл. Секреты не должны попадать в GitHub.
4. Если v2.30.14 уже работает, НЕ запускай SQL снова. Таблицы миграции
   database/078_real_user_monitoring.sql используются без изменений.
5. Запусти DEPLOY_FC_EDINET.bat.
6. Дождись успешного Next.js production build и отправки GitHub.
7. Убедись в Vercel Deployments, что новая сборка находится в статусе READY.
8. Проверь https://fc-edinet.vercel.app/api/version — версия 2.30.15.
9. Зайди в /admin/diagnostics/performance. Проверь фильтр устройств,
   статус приёмника и время последнего измерения.

СЕКРЕТЫ И ПРИЁМНИК
В Vercel Production и локальном .env.local должны быть настроены
SUPABASE_SECRET_KEY и ANALYTICS_IP_SALT. Не использовать NEXT_PUBLIC_ для них.
Если ANALYTICS_IP_SALT менялся, SHA-256 нового секрета должен совпадать
с private.analytics_ingest_config. Не менять salt без необходимости.

ПРОВЕРКИ
- npm run qa:all
- npm run typecheck
- npm run build
Установщик запускает проверки и production build автоматически, до git push.
В этой среде npm Registry недоступен; успешность production build должна
быть подтверждена на твоём компьютере и в Vercel после установки.

НОВОЕ В АДМИНКЕ
- Все устройства / Телефоны / Планшеты / Компьютеры.
- Последняя запись со временем Молдовы.
- Пустой период ≠ отсутствие ошибок.
- Для оценки проблемной страницы требуется >=10 измерений за выбранный период.
- LCP/INP/CLS/FCP/TTFB оцениваются отдельно; при малой выборке статус
  «Недостаточно измерений» сохраняется.

Без изменений: дизайн публичного сайта, Match Center, медиа, история клуба.
