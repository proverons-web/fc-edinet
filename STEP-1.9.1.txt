FC EDINET v1.9.1 — Automatic Translation RU -> RO

Что изменилось
- Русский остаётся основным языком редактора.
- При сохранении новости, биографии игрока, данных клуба, руководства, достижений, Hero, баннера и партнёра сервер автоматически создаёт RO-перевод.
- Перевод сохраняется в Supabase и не выполняется при каждом открытии страницы.
- Повторный API-запрос выполняется только если русский источник изменился.
- Можно включить «Зафиксировать ручной RO», чтобы автоматический перевод не перезаписывал ручную правку.
- /admin/translations показывает состояние переводов и позволяет перевести старый контент партиями до 12 материалов.
- Если API временно недоступен, русский контент всё равно сохраняется; публичная RO-версия использует существующий перевод или RU fallback.

Требуется
1. OPENAI_API_KEY в .env.local для локальной разработки.
2. OPENAI_API_KEY в Vercel -> Project -> Settings -> Environment Variables.
3. Не использовать NEXT_PUBLIC_ для API ключа.
4. OPENAI_TRANSLATION_MODEL необязателен; по умолчанию gpt-5.6-luna.

База
Migration database/020_auto_translation.sql добавляет служебные поля lock/hash/timestamp.

Проверка
- /api/version -> 1.9.1
- /admin/translations
- Создать/изменить новость на русском, сохранить, открыть сайт в RO.
