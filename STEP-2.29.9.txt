FC EDINEȚ v2.29.9 — ПУБЛИЧНАЯ СТАТИСТИКА ИГРОКОВ В ПРОТОКОЛЕ

Построено поверх v2.29.8; текущая структура и CSS публичного сайта не изменены.

1. В списке игроков каждой команды пять показателей: МИН / ГОЛ / АСС / ЖК / КК (RU), MIN / GOL / AST / GA / RO (RO).
2. Для завершённой статистики значения берутся из player_match_stats. RLS показывает эти строки публично только после завершения статистики матча.
3. До этого момента опубликованные события используются только для известных голов и карточек; неподтверждённые минуты, ассисты и остальные поля показываются как «—», а не выдуманный 0.
4. События сопоставляются по player_id и team_id; ручные имена сопоставляются внутри одной команды.
5. Карточки адаптируются под телефон без горизонтальной прокрутки. Переходы к профилям игроков, значки голов и замен сохранены.
6. Нет миграций, изменений формул подсчёта и обновлений глобального CSS.

Проверки: npm run qa:public-players; npm run qa:player-layout; npm run qa:all; npm run build.
Важный production smoke-test: открыть опубликованный матч с завершённой и с незавершённой статистикой, проверить игроков обеих команд.
Деплой: распаковать в отдельную папку рядом с предыдущими релизами; запустить DEPLOY_FC_EDINET.bat.
