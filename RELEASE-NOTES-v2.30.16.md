# FC Edineț v2.30.16 FULL — Multi-Competition System

Базовая версия: v2.30.15 FULL. **Это полный релиз, не патч.**

## Возможности

- Четыре типа соревнований: чемпионат, Кубок, товарищеские, другие.
- Админка `/admin/matches/competitions`: название RU/RO, тип, сезон, slug, герб, активность, редактирование существующего.
- Существующая `Liga 2 2026/27` остаётся с типом `league`; матчи, результаты и standings не переписываются миграцией.
- В форме нового/редактируемого матча список соревнований сгруппирован по типам; по умолчанию выбирается чемпионат.
- Календарь `/matches` поддерживает фильтр по типу и конкретному соревнованию, RU/RO. Перенесённые и отменённые встречи не пропадают.
- `/standings` и `/admin/standings` показывают только чемпионаты; серверный обработчик сохранения таблицы тоже проверяет тип.
- Главная выбирает турнирную таблицу независимо от типа ближайшего матча. Перенесённый матч без новой подтверждённой даты не занимает место следующего матча.
- Используется существующее хранилище гербов `teams` с действующими RLS-политиками.
- Защита связанных данных: если у соревнования есть матчи или турнирная таблица, нельзя поменять тип, сезон или деактивировать его.

## База

Перед публикацией выполнить **database/079_multi_competitions.sql**. Новых записей матчей и результатов SQL не создаёт. Никаких изменений в Production разработчик не выполнял.
