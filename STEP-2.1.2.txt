FC EDINEȚ v2.1.2 — Site-wide Visual Editor

Что нового:
- /admin/design стал единым конструктором визуальной части всех основных публичных страниц.
- Отдельные настройки Hero для Новости, Команда, Матчи, Турнирная таблица, Клуб, Медиа, Партнёры.
- Отдельные шаблоны для страницы новости, игрока и фотоальбома.
- Desktop / Mobile фото, фокус X/Y, zoom и высота Hero.
- Источник фона: системный, собственное фото, либо фото текущего материала для поддерживаемых шаблонов.
- Overlay: прозрачность и направление градиента.
- Выравнивание и максимальная ширина текста.
- Для обычных разделов можно переопределить RU/RO eyebrow, заголовок и описание; пустые поля используют штатный текст сайта.
- Для динамических шаблонов реальные заголовки/имена продолжают браться из контента.
- Независимые черновики, публикация и история версий для каждой страницы/шаблона.
- Главная сохраняет отдельный расширенный редактор с порядком секций.

База данных:
- database/024_sitewide_visual_editor.sql
- site_page_designs — опубликованные настройки.
- site_page_design_drafts — неопубликованные черновики.
- site_page_design_versions — история публикаций.

Важно:
На текущем production миграция 024 уже применена. Вручную SQL запускать не требуется.
