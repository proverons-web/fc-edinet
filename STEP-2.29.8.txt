FC EDINEȚ v2.29.8 — PUBLIC MATCH REPORT QUALITY

Изменения:
1. Мобильный протокол: фильтр событий Все / Голы / Карточки / Замены (по умолчанию все события).
2. Статистика: незаполненные показатели показываются как «—», а не как нули; диаграмма отображается только при данных обеих команд.
3. Диаграммы: независимый масштаб по наибольшему значению, равные показатели дают равную длину.
4. Матч-центр админки: количество найденных игроков при поиске и запрет замены игрока самим собой (клиент + сервер).
5. Без изменений формул минут, голов, карточек, триггеров и базы данных.

Установка: распакуйте рядом с предыдущими версиями и запустите DEPLOY_FC_EDINET.bat.
Проверки: npm run qa:public-match; npm run qa:all; npm run build (при настроенном .env.local).
Публичный интерфейс проверить на 320 / 360 / 390 / 768 / 1280 px, особенно матч с неполными показателями.
