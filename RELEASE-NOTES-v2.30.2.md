# FC Edineț v2.30.2 FULL — галереи матчей

## Что добавлено
- Альбомы можно привязывать к конкретному матчу при создании и редактировании в админке.
- Список матчей в редакторе содержит дату и команды (последние 150 по дате).
- На публичной странице матча появляется раздел с обложками только опубликованных альбомов этого матча.
- Привязка необязательна: существующая медиатека продолжает работать как раньше.
- Названия нового публичного блока RU/RO; мобильная адаптация, фокус клавиатуры и reduced-motion.

## Обязательное действие в Supabase
Выполнить `database/074_media_match_albums.sql` **перед** использованием новой админки. Колонка `match_id` связывается с `matches(id)`, а при удалении матча становится NULL. Миграция не удаляет существующие фото/альбомы.

## Проверка
`npm run qa:match-media`; после установки зависимостей `npm run deploy:check` (требует .env.local, не включён в ZIP).
