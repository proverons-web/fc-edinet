FC EDINEȚ v2.30.4 FULL — ПОШАГОВАЯ УСТАНОВКА

1. Сохраните резервную копию существующей папки сайта. Не удаляйте .env.local.
2. В Supabase Dashboard откройте SQL Editor и выполните database/075_media_match_videos.sql.
   Предыдущую database/074_media_match_albums.sql следует выполнить, если еще не применяли v2.30.2.
   Изменение не удаляет существующие записи: новые видео по умолчанию без привязки к матчу.
3. Распакуйте FC-Edinet-v2.30.4-FULL.zip в НОВУЮ папку.
4. Скопируйте в нее ваши рабочие локальные настройки .env.local (не публикуйте их).
5. Запустите DEPLOY_FC_EDINET.bat или выполните вручную npm install, затем npm run deploy:check.
6. После деплоя откройте /api/version и /admin/diagnostics: обе страницы должны показать 2.30.4.
7. Откройте /admin/media: создайте видео, выберите тип и матч. Проверьте /matches/[id].
8. Проверьте редактирование существующего видео в /admin/media/videos/[id]/edit.
9. Проверьте неопубликованное видео — оно НЕ должно выводиться на публичной странице матча.

ПРОВЕРКА БЕЗ ДЕПЛОЯ: node --experimental-strip-types scripts/qa-match-videos-v2304.mjs.
ПРИ ПРОБЛЕМАХ: сохраните текст ошибки из npm run deploy:check и /admin/media.
Замечание: SQL-миграция меняет базу; откат к предыдущей версии сайта требует отдельного плана.
