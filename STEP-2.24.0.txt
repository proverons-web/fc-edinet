FC EDINEȚ v2.24.0 — SEO / Performance / QA

SEO
- Expanded sitemap to all Club 2.0 routes.
- Added published custom pages to sitemap.
- Preserved dynamic news, player, match, media album and photo URLs.
- Hardened robots.txt: admin/account/auth/search/API are excluded.
- Added explicit noindex layouts for login/register.
- Added noindex metadata to the 404 page.
- Custom Site Builder pages now use the common canonical/OpenGraph/Twitter metadata helper.

PERFORMANCE / SECURITY
- Enabled compression and removed X-Powered-By.
- Added nosniff, strict referrer policy, SAMEORIGIN and restrictive browser permissions headers.
- Added long immutable cache headers for versioned/static brand assets.

QA
- Added npm script: npm run qa:site
- The script checks sitemap, robots, noindex surfaces, 404, manifest, Open Graph image, Club routes, custom pages and release version.

No Supabase migration is required for v2.24.0.
