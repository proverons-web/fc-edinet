FC Edineț v2.3.9 — Reference Homepage Redesign

Основа: v2.3.8.

Что изменено:
- Главная страница перевёрстана по предоставленному визуальному шаблону.
- Новый тёмно-синий Header с жёлтым акцентом и кнопкой "Билеты".
- Используется официальный логотип FC Edineț из предоставленного PNG.
- Hero: крупный спортивный заголовок, жёлтая CTA, карточка следующего матча справа.
- Hero сохраняет настройки Visual Editor: кадрирование background, zoom, X/Y текста и карточки матча, Desktop/Tablet/Mobile.
- Новый трёхколоночный блок: главная новость + последние новости + турнирная таблица.
- Новый блок состава на тёмно-синем фоне.
- Новый компактный блок партнёров.
- Footer стилизован в той же теме и использует официальный логотип.
- Существующие страницы, Match Center, статистика, Page Builder и админка сохранены.

База данных:
- Новая SQL-миграция НЕ требуется.

Установка:
1. Распаковать архив.
2. Скопировать рабочий .env.local из v2.3.8.
3. Запустить DEPLOY_FC_EDINET.bat.
4. Проверить /api/version -> 2.3.9.
5. Проверить главную страницу /.
