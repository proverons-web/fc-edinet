FC EDINET v1.9 — RU / RO

Что добавлено
=============
1. Переключатель RU / RO в верхней панели публичного сайта.
2. Выбранный язык сохраняется в cookie fc_locale и применяется на следующих страницах.
3. Переведены основные элементы публичного интерфейса:
   - шапка и меню;
   - главная;
   - новости;
   - команда и профиль игрока;
   - матчи и турнирная таблица;
   - клуб;
   - медиа;
   - партнёры;
   - вход, регистрация и личный кабинет;
   - footer и служебные страницы.
4. Для контента добавлены отдельные румынские поля. Они необязательные.
   Если румынское поле пустое, RO-версия автоматически показывает существующий русский текст.
5. В админке можно заполнять румынские версии:
   - новостей;
   - биографии игрока;
   - информации о клубе и стадионе;
   - руководства и достижений;
   - hero главной страницы;
   - специального баннера главной;
   - описания партнёра.
6. Стандартные категории новостей получили румынские названия.

База данных
===========
Миграция: database/019_i18n_ru_ro.sql
Для основной production-базы миграция применяется при подготовке релиза, вручную повторять её не нужно.

Работа с новой полной версией
==============================
Распаковать полный архив в новую папку, например:
E:\Projects\FC Edinet\fc-edinet-v1.9

Из предыдущей версии скопировать только .env.local.

PowerShell:
cd "E:\Projects\FC Edinet\fc-edinet-v1.9"
npm install
npm run deploy:check

После успешной сборки:
git init
git remote add origin https://github.com/proverons-web/fc-edinet.git
git fetch origin
git checkout -b main
git reset origin/main
git status
git add .
git commit -m "FC Edinet v1.9 RU RO multilingual"
git push -u origin main

После deploy проверить:
https://fc-edinet.vercel.app/api/version
Ожидаемая версия: 1.9.0
