FC EDINEȚ v2.29.6 — MATCH CENTER WORKFLOW IMPROVEMENTS

1. Распакуй новый FULL-пакет рядом с предыдущими версиями, сохрани .env.local в старой папке.
2. Запусти DEPLOY_FC_EDINET.bat. Скрипт восстановит локальные настройки, если они отсутствуют в новой папке.
3. Открой /api/version — ожидается 2.29.6.
4. /admin/match-center/[matchId] — проверь «Что осталось сделать» для завершённого матча.
5. Нажми пункт «Составы» / «События» / «Отчёт»: соответствующий раздел должен раскрыться и прокрутиться в область видимости.
6. Измени поле без сохранения: внизу появится предупреждение; раздел будет подсвечен.
7. Попробуй уйти со страницы / нажать другую ссылку: должно появиться подтверждение.
8. Измени поля в двух разных формах и сохрани одну: должно появиться подтверждение о других несохранённых изменениях.
9. Проверь публикацию завершённого матча с отсутствующим счётом (должна блокироваться) и с корректным счётом (после проверки допускается).
10. npm run qa:match-workflow; npm run qa:all; npm run build; npm audit --omit=dev.

Данных в Supabase это обновление не меняет. Новые миграции не нужны. Публичный интерфейс не менялся.
