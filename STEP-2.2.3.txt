FC EDINEȚ v2.2.3 — ПУБЛИЧНАЯ СТАТИСТИКА ИГРОКА
====================================================

ЦЕЛЬ
На публичной странице /team/[slug] показать статистику футболиста,
которая автоматически рассчитывается из завершённых матчей.

ЧТО ДОБАВЛЕНО
1. Выбор активного сезона прямо на странице игрока.
2. Главные показатели сезона:
   - матчи;
   - старты;
   - минуты;
   - голы;
   - ассисты;
   - гол + пас.
3. Дополнительные показатели:
   - выходы на замену;
   - жёлтые/красные карточки;
   - капитанство.
4. Для вратарей дополнительно:
   - сухие матчи;
   - сейвы;
   - пропущенные мячи.
5. Разбивка статистики по турнирам.
6. Последние 5 завершённых матчей игрока:
   - соперник;
   - счёт;
   - результат W/D/L;
   - турнир;
   - старт/замена;
   - минуты;
   - голы/ассисты;
   - сейвы для вратаря.
7. Черновики статистики никогда не выводятся публично.
8. Русская и румынская локализация блока.
9. Responsive UI для desktop/tablet/mobile.

БАЗА ДАННЫХ — ОДИН РАЗ
Перед использованием публичной статистики выполни:
  database/037_public_player_statistics.sql

Миграция разрешает публичному сайту видеть только workflow-строки
со статусом complete и ужесточает RLS player_match_stats: черновые
строки теперь доступны только Editor/Admin.

ПРОВЕРКА
1. Открой игрока, у которого есть завершённая статистика.
2. Убедись, что появился блок «Статистика сезона».
3. Переключи сезон.
4. Проверь сумму матчей/голов/ассистов с админкой.
5. Проверь последние матчи.
6. Открой игрока без статистики — должно быть корректное пустое состояние.
