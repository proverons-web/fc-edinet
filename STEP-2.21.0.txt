FC Edineț v2.21.0 — Page Builder Pro 2.0

Масштабная переработка UX редактора страниц.

Главное:
- единый workflow: секции → preview → настройки;
- drag-and-drop порядка секций;
- быстрый toggle видимости;
- простые варианты отображения вместо технических controls;
- пресет страницы в одном компактном selector;
- ширина, фон, выравнивание и spacing вынесены в понятные настройки;
- адаптивная сетка редактируется по устройствам;
- точные offset/scale/типографика спрятаны в «Дополнительно»;
- Hero ведёт в существующий Visual Editor;
- Undo/Redo сохранены;
- Draft/Publish сохранены;
- embedded-режим внутри Unified Site Builder больше не показывает второй preview;
- прямой Page Builder сохраняет собственный live preview;
- старые layout JSON и публичный рендер полностью совместимы;
- миграция БД не требуется.
