# FC Edineț v2.30.3 FULL — Media Gallery Pro

Исходная база: v2.30.2 FULL. Сохранены Fan Experience, медиатека, альбомы матчей, RU/RO, существующий дизайн и данные.

## Новое

- В открытой галерее добавлена прокручиваемая лента миниатюр с подсветкой активного снимка и прямым переходом к любому фото.
- Клавиши Home/End переходят к первому/последнему снимку. Сохранены стрелки, Escape и свайпы на сенсорных экранах.
- После закрытия галереи фокус возвращается к плитке, из которой открывали просмотр. При смене снимков диалог не теряет фокус.
- В редакторе альбома добавлена панель массового упорядочивания фотографий стрелками вверх/вниз с одной кнопкой сохранения.
- Сервер проверяет право редактора, принадлежность всех фото нужному альбому, отсутствие пропусков и повторов. Изменения публикуются без новой миграции.

## Проверка

`npm run qa:media-gallery` — 11 статических проверок. Обязательно выполнить `npm install` и `npm run build` локально перед публикацией: в среде подготовки npm-зависимости установить не удалось.

## Установка

1. Создать резервную копию текущих файлов и данных Supabase.
2. Распаковать полный архив в отдельную папку (не смешивать с файлами прежней версии).
3. Если SQL `database/074_media_match_albums.sql` из v2.30.2 ещё не применялся, сначала применить его в Supabase. Новых миграций в v2.30.3 нет.
4. Проверить настройки `.env.local` и выполнить `npm install` / `npm run build` или штатный DEPLOY_FC_EDINET.bat.
5. Проверить галерею альбома на компьютере и телефоне, а также изменение порядка фото в `/admin/media/[id]/edit`.

Примечание: массовое сохранение выполняется последовательными обновлениями; при ошибке сети на середине может понадобиться обновить страницу и повторить операцию.
